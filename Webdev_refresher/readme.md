# Web Refresher Project
A generic webpage designed to help you revisit the core HTML5, CSS and JavaScript skills. Tested on Chrome, Firefox and Opera using inspect element and toggle device toolbar. Works both on PC and mobile.
I made a simple page about a countryside holiday. The HTML was quite easy once I used the proper tags like header, nav and section. Getting the photos to sit next to each other with flexbox took a few tries. Same went with finding the ideal size for the burger dropdown menu. Adjusting the page for smaller screens was the part I found a bit harder so I kept checking it in the browser tools. The JavaScript for showing and hiding the tips was straightforward after I looked up classList.  One skill I would like to improve in Web Development is making better layouts and using CSS Grid more.
